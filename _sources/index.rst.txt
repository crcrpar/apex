APEX (A PyTorch Extension)
===================================

Some of the code here will be included in upstream PyTorch eventually. The intention of APEX is to make up-to-date utilities available to users as quickly as possible.

Installation instructions can be found here:  https://github.com/nvidia/apex#installation.
